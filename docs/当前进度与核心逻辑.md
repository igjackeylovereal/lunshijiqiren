> 面向：接手开发/调试的人或 Agent。先读《机器人操控手册》，再读本文。
> 最后更新：2026-11-19

---

## 1. 项目目标

用一台笔记本通过 SSH 隧道远程操控 bobac2 实训机器人，完成：

1. 人脸识别认证（进入系统一次即可）
2. 语音交互（语音综合应用：唤醒、闲聊、控制、导航）
3. SLAM 建图（网页端键盘遥控）
4. 地图点选导航（含“说地点名就去”的地点管理）
5. 建图/导航模式互切，全流程在网页完成，不需要 VNC

## 4. 业务状态机（core.RobotController）

```
IDLE ──开始巡航/导航──> PATROLLING / NAVIGATING ──到达/失败──> IDLE / FAULT
  │                          │
  │                     收到“去X”且未授权
  ▼                          ▼
WAITING_COMMAND <──── IDENTIFYING（确认停车与身份）
  │
  └── /api/stop ──> PAUSED（可恢复）
```

状态取值（前端展示用）：

```text
IDLE 待机 · PATROLLING 巡航中 · IDENTIFYING 确认停车与身份
WAITING_COMMAND 等待中文指令 · NAVIGATING 执行导航任务
PAUSED 已暂停 · FAULT 任务异常
```

指令解析 `parse_command()` 识别：

```text
“去教室 / 到教室 / 前往教室”   → navigate(place)
“开始巡航 / 巡逻”              → patrol()
“停下 / 停止”                  → stop()
“你在哪里 / 你能做什么”        → 固定问答
```

## 5. 三条核心数据流

### 5.1 语音导航

```
点“录音五秒并识别” → POST /api/listen
  → aiui_semantic 识别成文字
  → controller.dispatch(text)
  → parse_command(text) 命中 places[].name / aliases
  → navigate(place)：检查 place.pose 非空、map_id 与当前地图一致
  → LiveNavigation.send(pose)
  → 安全检查：health(scan_fresh & odom_fresh & localized)
  → actionlib 发 /move_base 目标
```

语音侧额外流程（语音综合应用）：

```
唤醒词“元宝” → 切换模式 / 闲聊 / 控制（前进、后退、左转、右转）
             → 导航（“我要去教室”）
```

### 5.2 地图像素点选

```
鼠标点击画布 → (u, v) + goalYaw
  → POST /api/navigation/goal {u, v, yaw}
  → pixel_goal(meta, u, v, yaw)   # 图像坐标 → map 米制
  → navigate(pose)
```

`pixel_goal` 数学：

```
x_map = origin_x + (u+0.5)*res*cos(a) - (h-1-v+0.5)*res*sin(a)
y_map = origin_y + (u+0.5)*res*sin(a) + (h-1-v+0.5)*res*cos(a)
```

### 5.3 建图遥控

```
POST /api/mode {mode:"mapping"} → bobac_mode.sh mapping
  → ctl stop → ctl up mapping（gmapping + app --mapping-teleop --mapping-keyboard）
建图页按住方向 → POST /api/mapping/control（每 100 ms 心跳）
  → KeyboardLease.tick(): 检查心跳新鲜、方向激光距离 ≥0.40 m
  → 发布 /cmd_vel
松手/失焦/断连 → stop
保存 → map_saver → maps/classroom_draft_<时间戳>.pgm/.yaml
```

## 6. 数据模型

### 6.1 地点（places）

```json
{
  "id": "place_2",
  "name": "教室",
  "aliases": ["教室", "去教室"],
  "pose": {"x": -0.67, "y": -4.57, "yaw": 0.0},
  "map_id": "008f86ef2988..."
}
```

- `pose = null` → 未标定，导航拒绝
- `map_id` 与当前 `/map` 哈希不一致 → 拒绝（防止换图后旧点）
- 同名保存会覆盖更新，不会重复

### 6.2 会议/会话

```text
data/sessions.json:  { "<token>": {"person": {...}, "last_active": ts } }
```

一次刷脸通过后写入，应用重启仍有效（所以不会每次重刷）。

## 8. 当前核心问题：定位链

### 8.1 症状链

```
车静止 → AMCL 不做更新（update_min_d=0.25, update_min_a=0.2）
→ /amcl_pose 与 map→odom 不发布/过期
→ 应用 position() 取不到 2 秒内的 TF → health.localized = false
   → 语音/网页报「雷达、里程计或定位尚未就绪」
→ move_base 代价地图等不到 map 坐标系
   → 报「导航 Action 不可用」
```

实测证据（11-19）：

```text
/amcl_pose 时间戳比当前时间早 330 秒
amcl 日志：MessageFilter [target=odom]: Dropped 100.00%
move_base 日志：Timed out waiting for transform ... target_frame map does not exist
```

### 8.2 已做的修复

```text
① navigation.launch 固化 AMCL 参数：
     /amcl/update_min_d        = 0.0
     /amcl/update_min_a        = 0.0
     /amcl/transform_tolerance = 1.0
   效果：/amcl_pose 由 330 s 未更新 → 3.0 Hz

② 回退 wheel_odometry.py 的 TF +0.3 s 超前补偿
   原因：TF 缓冲“最早数据在未来”，按激光时刻查询必然 extrapolation into the past
   验证：独立节点按扫描时刻查 odom←laser，稳定 OK

③ 应用在 master 之后重启（顺序问题）
   之前手工启动导致 rosnode list 里没有 /bobac_practicum、health 全 false
```

### 8.3 仍未确认

- 机器人 11-19 10:07 后**离线**（SSH 不可达），修复未做端到端复验
- 需要在机器人恢复后确认：
  1. `/amcl_pose` ≥2 Hz
  2. `tf map→base_footprint` 持续更新
  3. `/move_base/*` action 可用
  4. 语音“去教室”能真正发出目标

### 8.4 重要前提

AMCL 是**已知初始位姿**定位器。机器人必须摆回：

```
x = -1.767 m, y = -2.819 m, yaw = -1.532 rad（约 -87.8°）
```

或在地图上重新设初始位姿；否则收敛不到正确位置，导航会走偏。

## 10. 关键代码片段

### 10.1 健康检查（ros_adapter.py）

```python
def position(self):
    stamp = self.tf.getLatestCommonTime(self.config['map_frame'], self.config['base_frame'])
    if (self.rospy.Time.now() - stamp).to_sec() > 2:
        return None
    pos, quat = self.tf.lookupTransform(self.config['map_frame'],
                                        self.config['base_frame'], self.rospy.Time(0))
    return pos[0], pos[1], euler_from_quaternion(quat)[2]

def health(self):
    now = time.time()
    return dict(scan_fresh=now - self.last_scan < 1.5,
                odom_fresh=now - self.last_odom < 1,
                localized=self.position() is not None,
                map_id=self.map_id, ...)
```

## 12. 风险提示

- 机器人移动前必须确认 `localized=true` 且地图上位置与实际一致
- 不要手工 `setsid python app.py`，一律用 `ctl`
- 改 `navigation_project_20261105.json` 前先备份，写入必须原子
- `wheel_odometry` 的 TF 时间戳**不要**做超前补偿
- AMCL 的 `update_min_d/a` 保持 0，否则静止时定位会“过期”
