# 实践操作手册（按《实践计划书》逐条执行）

> 适用：`10.224.117.14` / 账号 `bobac2` / 密码 `root`
> 入口：双击 `D:\课设\console\启动台.bat` → 一键启动并打开
> 本手册只写**现在这台机器上真实可做的操作**，做不到的会明确标出。

## 1. 每天开始（约 2 分钟）

1. 机器人上电，等 1 分钟（`roscore` 与语音服务会自启，实测已在跑）。
2. 笔记本双击 `D:\课设\console\启动台.bat`。
3. 填 `10.224.117.14` / `bobac2` / `root`，点 **「一键启动并打开」**。
4. 看日志出现：

```text
ROSCORE=up  APP=up  PORT=up  MODE=navigation
MAP_YAML=.../classroom_navigation_20261105_094756.yaml
POSE_X=-1.7673  POSE_Y=-2.8188  POSE_A=-1.5321
```

5. 浏览器自动打开 `http://127.0.0.1:8765/`。

> 若模式是 `MODE=mapping/static`，在启动台上把模式切到"导航（已有地图）"，点「重启」。

## 2. 一次性标定：把"教室"记到地图上

**为什么必须做**：配置里 `places` 只有名字"教室"，坐标是空的；不标定，语音导航和巡航都会被拒绝。

步骤：

1. 登录网页（见第 3 节），进入 `/console`。
2. 确认页面显示的地图就是启动时加载的那张
   `classroom_navigation_20261105_094756.yaml`。
   > 页面上的「选择待加载地图」只是记一笔"待加载项"，**不会切换正在运行的 ROS 地图**；
   > 真要换图，用启动台的导航模式选对应 yaml 后点「重启」。
3. 在地图上**单击教室中央的空地**（白色区域），把"目标朝向"设成机器人停靠后应朝的方向（度），点 **「确认目标并导航」**。
4. 看着机器人走到该点；到点后确认它停稳。
5. 在页面下方"地点与连接"里点 **「将当前实际位置记录为教室」**。
6. 页面提示记录成功后，教室的 `x / y / yaw / map_id` 就写进配置了。

验证：

- 在"输入中文指令"框输入 `你在哪里` → 应回复地图坐标；
- 输入 `去教室` → 应回复"正在前往教室"。

> 标定与地图版本绑定。以后重建地图，要重新做这一步。

## 3. 人脸：录入、登录、测试

### 3.1 登录（每次进配置页）

1. 打开 `/`，点 **「开始验证」**。
2. 单人正脸对准相机，距离 1～1.5 m，正常光照。
3. 稳定识别约 2 秒后自动进入 `/console`。
4. 陌生人会提示"不是授权人员"并记事件；无脸、多人、画面太暗不会当成陌生人。

### 3.2 补录其余三人（每人本人同意、单人入镜）

1. `/console` → "相机与身份" → 下拉选人员（周高定 / 林宸涵 / 李胜洋）。
2. 勾选"本人同意录入，且画面中只有所选人员"。
3. 点 **「录入 30 张人脸样本」**。
4. 按提示缓慢改变距离、小幅左右转头；约 25～60 秒完成。
5. 换下一个人重复。

### 3.3 人脸 90% 测试（成绩要用这个，不是录入）

| 项 | 要求 |
|---|---|
| 测试集 | 4 名已录入人员 + 2 名未录入陌生人 |
| 次数 | 每人 20 次进场，共 120 次 |
| 条件 | 正常光照、正面、1～1.5 m；再补一轮偏暗/侧脸 |
| 记录 | 预期身份、实际结果、响应时间、是否误接受 |
| 计算 | 正确次数 ÷ 总次数；陌生人误接受单独统计 |

用表格记（可直接抄进报告）：

| 序号 | 人员 | 光照 | 距离 | 预期 | 实际 | 耗时(s) | 备注 |
|---|---|---|---|---|---|---|---|
| 1 | 孟熙恒 | 正常 | 1.2m | 通过 | | | |

## 4. 没有地图时：建图

1. 启动台模式切到 **「建图」** → 点「重启」。
2. 浏览器打开 `/mapping`。
3. 页面默认是"首次微动测试"：只有前进，速度 0.05 m/s，每次最多 0.6 秒（约 3 cm），累计约 10 cm 会停。
4. 先点 **「重新启用操作」**，按住 **「按住前进微动 ↑」** 试 2～3 次，确认方向对、松手能停。
5. 现场确认安全后，进入完整键盘模式（`up mapping` 已带 `--mapping-keyboard`），用 **W/A/S/D 或方向键**行驶；松开、切窗、离开页面、断网都会停车。
6. 走位：贴墙绕外圈 → 每个门口进出 → 主通道走中线 → 最后回起点闭环。
7. 点 **「停车并保存当前建图进度」**，记录保存的文件名。
8. 建图完成后回启动台，切回"导航"模式重启，再做第 2 节的标定。

> 雷达没覆盖的方向（当前约 240°）不会允许后退/转向，这是保护，不要为了好开而关掉。

---

## 5. 有图时：单点导航

1. `/console` 打开后先确认右上角模式徽标正常、地图已加载（能看到灰度地图与机器人位置）。
2. 地图上单击目标空地 → 设目标朝向（度）→ **「确认目标并导航」**。
3. 观察：状态文字、机器人实际运动。
4. 需要中止：点 **「取消导航／停车」**。

判据：车能规划出路径、绕开障碍、到达后停稳；失败时页面显示原因而不是假装到达。

## 6. 完整闭环演示（计划书典型场景）

前置：第 2 节标定完成、第 3 节登录成功、急停有人守。

```text
① 在 /console 点"开始模拟巡航"按钮（按钮文案是旧的，实机模式下执行的是真实巡航，
   依赖"教室"已标定；也可用语音"开始巡航"，但需先完成身份识别）
② 机器人驶向"教室"
③ 你走到它前方 1～1.5 m，正对相机
④ 页面识别出你 → 状态机 cancel 导航 → 停车（IDENTIFYING → WAITING_COMMAND）
⑤ 在"输入中文指令"里说/输入"你在哪里" → 播报坐标
⑥ 说/输入"去教室" → 机器人规划并前往
⑦ 到点后状态变为到达；点"取消当前任务"收尾
```

注意：

- 第④步的"停车"是**软件取消导航**，不替代物理急停。
- 若第③步没反应，看"相机与身份"里的 `faceStatus` 与相似度；太远/太暗/侧脸都会被拒。
- 语音用 **「录音五秒并识别」**，回复用 **「播报当前回复」**；电脑要先点过一次"在电脑扬声器播放回复"。

## 7. 三个指标怎么测、怎么写

### 7.1 人脸识别率

见 3.3。报告里写：样本数、正确率、误接受率、平均响应时间、测试条件。**不要把相似度当准确率。**

### 7.2 导航成功率

| 次数 | 目标点 | 结果（到达/失败/取消） | 耗时 | 是否避障 | 备注 |
|---|---|---|---|---|---|
| 1 | 教室 | | | | |

建议 10 次，含 2 次中途放障碍物。

### 7.3 障碍物"识别率"

当前系统做的是**激光占用检测 + 导航避障**，不是"墙体/桌椅/设备"的类别识别，所以不能报"类别识别 90%"。

能测的是：

| 次数 | 障碍物 | 放置位置 | 是否停车/绕开 | 最近距离 |
|---|---|---|---|---|
| 1 | 椅子 | 通道中 | | |

报告写法（如实）：

> 本系统采用二维激光占用栅格与 move_base 局部避障，未实现障碍物语义类别识别；课程计划书中"障碍物识别准确率≥90%"的类别口径**当前未覆盖**，仅提供避障行为成功率数据。

如果老师坚持要类别识别，需要另做 YOLO/OpenCV 检测模块，这是新的开发任务，不在本次操作范围内。

## 10. 出问题先看这里

| 现象 | 处理 |
|---|---|
| 启动台连不上 | 账号必须 `bobac2`，密码 `root`；root 会被拒 |
| 网页 403 | 本机 8765 被占用（多半是上次的 `ssh -L`），关掉重试 |
| "请先完成授权人员身份识别" | 先登录（`/`），或人脸丢失后重新识别 |
| "地点未标定" / 巡航拒绝 | 回第 2 节，记录"教室"位置 |
| 语音没反应 | 点过一次"在电脑扬声器播放回复"；看 `voiceStatus` |
| 识别不出 | 靠近到 1～1.5 m、正脸、补光；看 `faceDetails` 的相似度 |
| 车不动 | 看页面状态与急停；导航模式下不要用建图页的按键 |
| 地图选点后不动 | 确认地图已加载、AMCL 已定位（位姿不是 0,0,0 才正常） |
