# bobac 笔记本一键控制（网页版）操作手册

> 目标：**只在这台笔记本上操作**。双击一个程序 → 自动连机器人 → 自动拉起运行栈 → 自动开网页。
> 机器人端不需要再开终端敲任何命令（除非你想手工排查）。

---

## 0. 先说明：之前为什么连不上

我实际连上机器人排查后确认了三个原因，不是网络问题：

| 现象 | 真实原因 |
|---|---|
| `ssh root@...` 失败 | **root 账号不可登录**。机器人上的账号是 `bobac2`，密码 `root` |
| 网页 `http://机器人:8765` 打不开 | 应用只监听**机器人本机回环** `127.0.0.1:8765`，必须走 SSH 隧道 |
| 隧道通了仍 403 | 应用校验 `Host` 必须是 `127.0.0.1:8765`，本地端口不能改 |

当前机器人状态（我 2026-11-05 实测）：

```text
HOST=reinovo
ROSCORE=up   APP=up   PORT=up   VOICE=up
MODE=navigation
MAP_YAML=.../maps/classroom_navigation_20261105_094756.yaml
POSE_X=-1.7673  POSE_Y=-2.8188  POSE_A=-1.5321
NODES=13
```

也就是说**栈本来就在跑**，缺的只是一个能自动连上去的入口。

## 1. 第一次使用

1. 双击 `D:\课设\console\启动台.bat`
   （首次会自动建 `.venv` 并装 paramiko；已经装过就直接开）
2. 填：IP 留默认 **`reinovo.local`** 即可（机器人 IP 会随网络变化，mDNS 名字不变；
   连不上时启动台会自动再试 `10.109.40.14`、`10.224.117.14` 两个历史地址），用户 `bobac2`，密码 `root`
3. 点 **「一键启动并打开」**

它自动做四件事：

```text
① 上传最新控制脚本到机器人（每次连接都覆盖上传，带版本号 CTL_VERSION）
② 读取运行状态（roscore / 应用 / 模式 / 地图 / 位姿）
③ 应用没跑就按所选模式启动；已经在跑就跳过（不会打断现场）
④ 建立 127.0.0.1:8765 隧道 → 等 HTTP 200 → 用允许自动播放的浏览器打开
```

浏览器打开的是机器人上的真实网页，登录、地图、建图、导航全在里面。

## 2. 三个运行模式

控制台上方选模式，再点「一键启动并打开」或「重启」：

| 模式 | 机器人端动作 | 适用 |
|---|---|---|
| **导航（已有地图）** | 起 `navigation.launch`（底盘+雷达+map_server+amcl+move_base）+ 应用 `--allow-motion` | 已有 `classroom_navigation_*.yaml`，做任务演示 |
| **建图** | 起 `mapping.launch`（底盘+雷达+gmapping）+ 应用 `--mapping-teleop --mapping-keyboard` | 第一次进教室、场地变了 |
| **静态（不运动）** | 只起 `static.launch`，应用不带运动权限 | 调人脸、调语音、答辩演示界面 |

要点：

- 导航模式会带上**地图路径和初始位姿**（x/y/yaw）。点「状态」会自动把机器人当前正在用的值填进来；重启时沿用，不会把位姿重置成 (0,0,0)。
- 两种模式互斥，切换时脚本会先停掉旧 launch 和应用。
- 建图/导航的底盘点位与速度限制沿用你项目里已有的安全参数，本工具不改任何阈值。

## 3. 网页里做什么

| 页面 | 用途 |
|---|---|
| `/` | 人脸登录（单人正脸、多帧稳定才通过） |
| `/console` | 配置页：地图列表与选择、地图选点导航、语音指令、人员录入、状态 |
| `/mapping` | 建图页：键盘 W/A/S/D 或方向键遥控，松开停车，空格停车并暂停 |

网页里已有的保护（服务端权限校验、地图 ID/坐标校验、运动开关、数据新鲜度、失联停车）全部保留，本工具没有放宽任何一项。

## 4. 控制台按钮

| 按钮 | 作用 |
|---|---|
| 一键启动并打开 | 上面那四步 |
| 打开网页 | 隧道已建立时直接开浏览器 |
| 停止 | 停应用 + 停 launch，**保留 roscore**（下次启动更快） |
| 重启 | 停止后按当前模式重新拉起，位姿沿用 |
| 状态 | 打印 ROS/应用/模式/地图/位姿/节点数，并回填位姿与地图 |
| 日志 | 看机器人上 `app_console.log` 最后 60 行 |

## 5. 出问题时

| 现象 | 处理 |
|---|---|
| 连接失败 / Authentication failed | 账号必须是 `bobac2`，密码 `root`；root 登录会被拒绝 |
| 网页 403「仅允许本机或 SSH 隧道访问」 | 本机端口必须是 8765；把占用 8765 的旧 `ssh -L` 关掉 |
| 网页打不开但状态显示 APP=up | 点「打开网页」；仍不行点「重启」 |
| 本机 8765 被占用 | 关闭上次遗留的隧道进程，或重启电脑 |
| 应用起不来 | 点「日志」看 `app_console.log`；常见是相机被 NiViewer 占用、地图文件不存在 |
| 导航模式提示没有地图 | 先切到建图模式建图，在网页 `/mapping` 里保存，或让脚本 `save-map` |
| 车不动 | 先确认网页里运动开关、急停、雷达/里程计新鲜度；软件不停车不代表物理安全 |

## 6. 不用控制台时（等价命令，备用）

机器人上：

```bash
bash ~/bobac_practicum_ctl.sh status
bash ~/bobac_practicum_ctl.sh up nav /home/bobac2/bobac_practicum_run/maps/xxx.yaml -1.767 -2.819 -1.532
bash ~/bobac_practicum_ctl.sh up mapping
bash ~/bobac_practicum_ctl.sh up static
bash ~/bobac_practicum_ctl.sh stop          # 保留 roscore
bash ~/bobac_practicum_ctl.sh stop --all    # 连 roscore 一起停
bash ~/bobac_practicum_ctl.sh save-map classroom_20261105
bash ~/bobac_practicum_ctl.sh maps
bash ~/bobac_practicum_ctl.sh log app 100
```

笔记本上等价的手工隧道：

```powershell
ssh -N -L 127.0.0.1:8765:127.0.0.1:8765 bobac2@10.224.117.14
```
